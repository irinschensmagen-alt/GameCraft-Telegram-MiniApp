# GameCraft AI — Telegram Bot + Mini App + OpenRouter AI

Финальная сборка для домашнего задания.

- реальная интеграция AI API OpenRouter;
- бесплатный роутер `openrouter/free`;
- AI анализирует педагогический запрос и формирует часть ответа;
- пользовательская лексика не подменяется;
- 23 игровые механики;
- тестовый режим для проверяющего Telegram ID `328761045`;
- для остальных — 3 AI-запроса в сутки (счётчик хранится в памяти процесса и сбрасывается при перезапуске бота);
- `.env` с секретами не входит в архив и не должен попадать в GitHub.

Схема: Педагог → Telegram → OpenRouter AI API → GameCraft AI → Mini App.
