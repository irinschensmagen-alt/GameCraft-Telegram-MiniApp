# GameCraft AI — Telegram Bot + Mini App + OpenRouter AI

Финальная сборка для домашнего задания.

## Реализовано
- настоящий OpenRouter AI API для всех пользователей без исключений;
- бесплатный маршрут модели `openrouter/free`;
- AI анализирует педагогический запрос и участвует в формировании ответа;
- пользователь сам задаёт учебный материал;
- 23 игровых механики;
- Telegram Mini App;
- одинаковый лимит: 3 AI-запроса в сутки на каждого Telegram-пользователя;
- `.env` с секретами не входит в архив и не должен попадать в GitHub.

## Схема
Пользователь → Telegram → OpenRouter AI API → GameCraft AI → игровая механика → Mini App

Тьютер и другие слушатели проходят тот же путь, что и любой пользователь.

- Учебные пары распознаются только через знак `=`; дефисы в уровнях и словах (например, `Pre-A1`) не считаются разделителями.
