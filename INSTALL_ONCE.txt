Рабочая папка:
C:\MyProjects\GameCraft-Telegram-MiniApp

GitHub-папка:
C:\Users\HP\Documents\GitHub\GameCraft-Telegram-MiniApp

1. Распакуйте всё содержимое архива в рабочую папку с заменой файлов.
2. Ваш локальный .env не удаляйте. В архиве .env нет.
3. В .env должны остаться:
TELEGRAM_BOT_TOKEN=...
MINI_APP_URL=https://irinschensmagen-alt.github.io/GameCraft-Telegram-MiniApp/
OPENROUTER_API_KEY=...

4. Скопируйте содержимое архива в GitHub-папку с заменой файлов.
5. GitHub Desktop:
Summary: Use OpenRouter AI for all users
Commit to main
Push origin
6. Перезапустите бота:
Ctrl+C
npm run dev

Теперь ВСЕ пользователи, включая тьютора, используют настоящий OpenRouter API.
Лимит по умолчанию: 3 AI-запроса в сутки на пользователя.

Надёжность: на один запрос бот делает до 3 внутренних попыток OpenRouter; пользовательский лимит считается только после успешного ответа.
